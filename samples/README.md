# Сэмплы

Положите сюда живые записи — они заменят синтез:

* файл со словом **`drums`** в имени (барабанный луп) — режется по атакам,
  удары раскладываются по ролям автоматически;
* файл со словом **`guitar`** — из него берётся нота, которой дальше играются
  все остальные. Слово `distorted` в имени означает, что сэмпл уже с
  перегрузом и второй раз через усилитель не пойдёт.

Подойдут `wav`, `flac`, `ogg`, `mp3`. Сами аудиофайлы в репозиторий не
попадают (см. `.gitignore`) — у них своя лицензия, и место им на диске, а не
в истории проекта.
